# 🇮🇳 नमस्ते Hindi - Easy, Fast & Fun Hindi Learning Web App

A web-based Hindi learning application designed specifically for students to master Hindi quickly, intuitively, and with high engagement.

## ✨ Key Features

1. **🔊 Crystal Clear Audio for Every Letter, Word & Phrase**:
   - Every letter, vowel sign (मात्रा), vocabulary word, dialogue, and quiz question has a dedicated audio button.
   - Built-in **Turtle Mode (🐢 0.7x speed)** for slow, clear beginner articulation alongside **Normal speed (1.0x)**.
   - Dynamic animated audio wave indicator when sound is playing.

2. **📈 Progressive 6-Level Learning Roadmap**:
   - **Level 1: वर्णमाला (Alphabet & Sounds)**:
     - 13 स्वर (Vowels) and 30 व्यंजन (Consonants).
     - Visual mnemonics with emojis (क से कबूतर 🕊️, अ से अनार 🍎).
     - Interactive **Trace & Write** digital slate to practice handwriting Devanagari script.
     - **Voice Mic Practice** to speak Hindi aloud and get instant feedback.
   - **Level 2: मात्राएँ और सरल शब्द (Matras & Word Magic)**:
     - All 10 Hindi Matras explained with visual formulas (क + ा = का).
     - **Interactive Syllable Builder**: Pick any consonant + any matra to hear the resulting sound immediately.
     - 2 & 3 letter words with syllable breakdown (घ + र = घर).
   - **Level 3: रोज़मर्रा के शब्द (Everyday Vocabulary)**:
     - Numbers 1-10 with Hindi numerals (१, २, ३...).
     - Colors (लाल, नीला, पीला, हरा...).
     - Animals, Family members, and Fruits with vibrant flashcards.
   - **Level 4: बोलचाल के वाक्य (Daily Conversations & Greetings)**:
     - Practical conversational dialogues for school, greetings, and daily life.
     - Grammar tips and cultural context hints.
   - **Level 5: वाक्य निर्माण (Sentence Puzzle Master)**:
     - Interactive word tile puzzle to assemble sentences in proper Hindi **Subject + Object + Verb (SOV)** word order.
   - **Level 6: महासंग्राम क्विज़ (Super Arcade Challenge)**:
     - Audio ear-training questions, picture matches, and vocabulary challenges.
     - 3-Heart life system, cheerful sound effects, confetti celebrations, and star ratings (⭐ ⭐ ⭐).

3. **🎮 Gamification & Student Engagement**:
   - XP Points system, streak tracker, star badges, and encouraging Hindi praise (शानदार!, बहुत बढ़िया!, शाबाश!).
   - Toggle English phonetic hints on/off to challenge students to read pure Hindi script.

## 🚀 How to Run the App

1. Ensure dependencies are installed:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open your browser at:
   ```
   http://127.0.0.1:3000/
   ```
